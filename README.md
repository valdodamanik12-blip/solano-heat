An original open-world crime game set in the fictional city of Solano Bay, written from scratch in plain JavaScript — no engine, no libraries, no assets, no network requests. Explore an 11×9-block city with a bay, working docks and a beach; walk it on foot or steal any of six vehicle types and drive; outrun a five-star heat system with pursuing police; fight with fists and a pistol; and run a five-mission story chain for fixer Dario Klem — a package run, a debt collection, a guarded car theft, a courier job under full heat, and a four-star escape to the respray garage. Money, story progress and your gun persist in localStorage between visits.

Play it by opening `game/index.html` in a desktop browser, or serve the folder with `node serve.ts` and visit http://localhost:8080/game/. Hand it in with `node main.ts`, which copies the game and screenshots to the output directory and writes the dossier.
