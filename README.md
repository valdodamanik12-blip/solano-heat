# SOLANO HEAT

[![make.fun · gta6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01?utm_source=github&utm_medium=badge&utm_campaign=gta6-01)

An original open-world crime game in the fictional city of Solano Bay, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore an 11×9-block city on foot and by car, steal and drive six vehicle types, outrun a heat-star wanted system with pursuing police, work a five-mission story chain for fixer Dario Klem, fight with fists and pistol, and save your progress — all in static files with no build step: open `game/index.html` in a desktop browser and play.

Built by [V4ldoo](https://make.fun/r/f1z3jcpa) for make.fun.
